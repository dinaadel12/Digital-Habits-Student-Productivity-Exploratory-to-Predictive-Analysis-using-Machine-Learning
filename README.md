Digital Habits & Student Productivity Exploratory to Predictive Analysis using Machine Learning

This project explores the relationship between digital habits and student productivity, and builds predictive models to estimate productivity levels based on behavioral patterns.

Problem:

With increasing digital usage among students, it becomes important to understand how screen time, social media usage, and study habits affect productivity. This project aims to analyze these patterns and build a predictive model.

Approach:

Data cleaning and preprocessing (handling missing values, encoding, scaling).
Exploratory Data Analysis (EDA) to identify trends and correlations.
Statistical analysis to understand relationships between variables.
Built machine learning models to predict student productivity.
Evaluated model performance using standard metrics.

Results:
Extracted meaningful insights about the impact of digital habits on productivity.
Developed a predictive model to estimate student productivity levels.
Provided visual and data-driven conclusions to support decision-making.

Tools & Technologies:

Python, Pandas, NumPy, Scikit-learn, Matplotlib, Seaborn
